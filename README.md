# Note Calendar (Obsidian Plugin)

> 基于 [Is-Ming/obsidian-note-calendar](https://github.com/Is-Ming/obsidian-note-calendar) v1.0.1 修改的增强版本

一个 Obsidian 日历插件，支持显示农历日期、节假日、调休安排、二十四节气，并允许在日历中创建/更新关联笔记。

## ✨ 新增/修改功能（v1.4.1）

### 新增
- 🆕 **香港假期标记视觉区分** - 香港"休"标记改为**圆圈 + 主题色（紫色）**，大陆"休"保持**方框 + 红色**，形状与颜色双重区分，一眼可辨

## ✨ 新增/修改功能（v1.4.0）

### 新增
- 🆕 **香港公众假期显示（可选）** - 设置面板新增"显示香港公众假期"开关，开启后在日历上标记香港公众假期（含耶稣受难节、复活节星期一、佛诞、中秋节翌日、重阳节、圣诞节等香港特有假期）。数据来自香港政府宪报公告（2026 剩余 + 2027 年），假期名优先显示，与大陆节假日独立维护

## ✨ 新增/修改功能（v1.3.1）

### 修复
- ✅ **修正 2027 年节假日预填策略** - 仅标记节日当天为"休"（元旦 1/1、春节 2/6、清明 4/5、劳动节 5/1、端午 6/9、中秋 9/15、国庆 10/1），不再预填多天连休。连休与调休班日待国务院公布后补充，避免误导（如 2027 清明为周一，与前后周末自然连休，不应额外标记 4/6、4/7）

## ✨ 新增/修改功能（v1.3.0）

### 修复
- ✅ **节假日数据延期至 2027 年** - lunar.js 内置数据仅覆盖到 2026-10，通过 `HolidayUtil.fix()` 追加 2027 年法定节日放假数据（元旦、春节、清明、劳动节、端午、中秋、国庆），2027 年起日历仍能显示节日与"休"标记
  - ⚠️ 调休上班日（"班"）需待国务院每年 11 月底公布后才能确定，本次仅预填放假日期

## ✨ 新增/修改功能（v1.2.0）

### 性能优化
- 🚀 **全库扫描并行化** — 初始扫描并行读取所有文件信息，大 vault 不再卡顿
- 🚀 **增量文件索引** — 文件创建/修改/重命名/删除时只更新单个文件的缓存，不再全库重扫
- 🚀 **农历计算缓存** — 农历/节气/节假日/调休计算按日期缓存，切换月份、重渲染不再重复计算

### 新增
- 🆕 **键盘方向键导航** — 日历聚焦后用 ↑↓←→ 移动选中日期（跨月自动翻页），Enter 打开当天首个笔记

### 修复
- ✅ **文件夹路径误匹配** — 设置"日记"文件夹不再误匹配"日记本"等同前缀文件夹
- ✅ **周数算法统一** — 周记标题与网格显示的周数一致（统一 ISO 8601）
- ✅ **重命名笔记标题即时更新** — 绕开文件系统时序问题，标题可靠刷新
- ✅ **设置项防抖** — 文本/字号输入不再每敲一键就存盘+全量重渲染

### 清理
- 🧹 移除全部调试日志、死代码，对话框样式迁入 CSS，代码净减约 200 行

## ✨ 新增/修改功能（v1.1.0）

### 修复
- ✅ **创建笔记时输入已有文件夹路径不再报错** — 修复路径拼接导致 Obsidian API 查询失败的问题
- ✅ **创建笔记支持日记模板** — 新建笔记时自动应用 Obsidian 核心"日记"插件的模板
- ✅ **白色背景** — 默认背景色改为白色，更适合浅色主题

### 新增
- 🆕 **默认创建文件夹路径** — 设置面板新增配置项，创建笔记时自动填充默认路径
- 🆕 **背景颜色可自定义** — 设置面板新增颜色选择器，可自由调整日历背景色

## 安装方法

1. 下载本仓库所有文件
2. 放入 Obsidian Vault 的 `.obsidian/plugins/note-calendar/` 目录
3. 重启 Obsidian
4. 在设置中启用 Note Calendar 插件
